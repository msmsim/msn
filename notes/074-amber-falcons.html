Simple starter pack for producing executive-grade information artefacts:

  • Butterick’s Practical Typography
  • Barbara Minto’s Pyramid Principle and SCQA approach
  • ASD-STE100 Simplified Technical English
  • Edward Tufte’s visualisation design principles

Then add:

  • A context bucket filled with supporting evidence and background information
  • Explicit medium constraints (e.g. text length and genre, number of slides and approximate layout templates)

Mash all the above together into a folder in sight an agent and run with it.
